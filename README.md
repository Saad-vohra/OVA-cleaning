## 🚀 How to Run on Localhost

### Option 1: Double-Click (Easiest on Windows)
Simply double-click the **`start-localhost.bat`** file in this folder. It will start the server and automatically open `http://localhost:3000` in your default browser.

### Option 2: Using Node.js / npm
```bash
npm start
```
or:
```bash
node server.js
```
Then visit **[http://localhost:3000](http://localhost:3000)** in your browser.

### Option 3: Using Python
```bash
python -m http.server 3000
```
Then visit **[http://localhost:3000](http://localhost:3000)** in your browser.

## 📁 Project Structure

- `index.html`: Main Home Page (Home 01)
- `index-2.html`: Alternative Home Page (Home 02)
- `page-about.html`: About Us Page
- `page-services.html` & `page-service-details.html`: Services & Service Details
- `page-projects.html` & `page-project-details.html`: Portfolio & Project Showcases
- `page-pricing.html`: Service Pricing Plans
- `page-contact.html`: Contact & Consultation Booking
- `images/`: Brand assets:
  - `logo.png`: Transparent horizontal brand logo (Header & Sticky navigation)
  - `logo2.png`: Transparent high-contrast logo (Footer & Mobile menu)
  - `favicon.png`: 128x128 brand emblem icon
  - `ova-logo-vertical.png`: Full client vertical badge with transparent background
  - `icons/preloader.png`: Animated loading spinner with OVA emblem
- `server.js`: Built-in zero-dependency static HTTP server for localhost development
